What an Airbnb iCal file gives you

An iCalendar file contains date ranges for reservation and availability events. For a turnover workflow, the important operational moment is the end of a stay: that is when the property normally needs to be reset before the next guest.

TurnoverCue looks at those calendar events, filters Airbnb events it can identify as blocked/not available or cancelled, and builds a chronological cleaning schedule.

Why use iCal for cleaner scheduling?

No new host loginUse an exported calendar instead of giving another tool your booking-platform password.
Minimal dataThe workflow cares about property and dates, not payouts or guest financial information.
Portable outputCopy a cleaner message or export a CSV rather than forcing the cleaner into another app.

A limitation worth knowing

Calendar feeds can contain owner blocks and other unavailable periods as well as reservations. TurnoverCue has Airbnb-aware filtering for identifiable blocked/not-available events, but calendar formats vary. Always verify critical same-day turns against the booking platform.

Airbnb's current export route

Airbnb's Help Center currently directs home hosts on desktop to Calendar → listing → Availability → Connect calendars → Connect to another website. The exported link can then be used with other iCal-based calendars.

Frequently asked questions

What does .ics mean?

ICS is the common file extension for iCalendar data, a standard format used by booking platforms and calendar applications.

Does TurnoverCue continuously sync the calendar?

Not in the current free version. You upload the calendar file when you want to generate the schedule. Automatic read-only sync is a possible future Pro feature.

What happens to blocked dates?

For Airbnb-identified feeds, TurnoverCue ignores events labelled blocked or not available where identifiable, along with cancelled events.
