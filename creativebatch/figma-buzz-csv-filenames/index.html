The problem

Figma Buzz users have repeatedly asked for more control over spreadsheet-driven frame and export naming. Buzz now auto-names bulk-created frames from CSV-tag content, but current users still report needing to disable or fine-tune that behaviour and choose the tags that matter.

The pain becomes obvious at scale: dozens of languages, hundreds of OpenGraph images, product catalogs, or campaign batches where a content pipeline expects a predictable naming convention. CreativeBatch does not replace Bulk Create; it reuses the source CSV after export to apply your own filename rule.

How the browser workaround works

1. Export the assetsDownload the files from Buzz normally.
2. Drop the same CSVCreativeBatch exposes the CSV column headers as filename tokens.
3. Verify and downloadPreview every row-to-file mapping, then download a renamed ZIP and manifest.

Why use a browser tool instead of a Figma plugin?

A plugin is the cleaner solution when your organization allows it. CreativeBatch's current niche is different: it does not need Figma account access or plugin installation. That can be useful for a quick workaround, locked-down environments, or teams that only receive exported files plus the source spreadsheet.

The important limitation

CreativeBatch currently maps files to CSV rows by order. If the exported file order does not correspond to the spreadsheet row order, the mapping can be wrong. The tool blocks obvious file-count mismatches and duplicate generated names, but you should visually verify the preview before using the ZIP in production.

Example filename patterns

{page_slug}_{language}_{id}

{campaign}_{market}_{n}

{sku}_{variant}_{part}

Any CSV header can be used as a token, along with built-in numbering, date, original filename and part tokens.
